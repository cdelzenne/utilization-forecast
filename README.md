# APAC Utilization Forecast

Prototype dashboard that forecasts consultant utilization for the next 8 weeks across the APAC offices of two Brandtech Group business units (fifty-five and Jellyfish), and helps staffing managers find who is available for a given role, expertise and period.

> **All data in this repository is synthetic.** Every name, client and figure was generated by `scripts/generate_sample_data.py` to prototype the workflow. None of it describes real people, clients or business results.

## What it shows

- **Headline figures** — forecast utilization vs target, confirmed bookings, hours below target (≈ idle FTE), people over capacity, headcount in view.
- **Find who's available** — a plain-language search such as *"I need a cloud specialist with GCP certification for 3 weeks starting Nov 23"*. It reads title, expertise, start, duration, workload, office and business unit, shows how it understood the request as editable controls, and ranks people as Available / Partly / Closest with free hours per week.
- **Weekly forecast vs capacity** — confirmed hours plus probability-weighted pipeline, against target.
- **Office × week heatmap**, **utilization by job title** and **by expertise / certification**.
- **People to act on** — anyone over capacity in a week, or forecast more than 20 points under target.
- **Open pipeline** that could absorb the gap, filtered like the rest of the page.

Filters: business unit, office (Hong Kong, Shanghai, Shenzhen, Singapore, Bangkok, Jakarta, Seoul, Tokyo), 14 job titles, and 15 technology-partner certifications.

## Method

| Term | Definition |
|---|---|
| Capacity | 40 h/week less office public holidays and planned leave |
| Confirmed | Hours booked on signed projects |
| Weighted pipeline | Tentative hours on open opportunities × stage probability (Qualified 25%, Scoping 40%, Proposal 50%, Shortlisted 60%, Verbal 75%) |
| Forecast utilization | (Confirmed + weighted pipeline) ÷ capacity |
| Target | Billable target by title (e.g. Consultant 85%, Consulting Manager 65%), capacity-weighted |

The forecast window is the 8 weeks starting Monday 16 Nov 2026.

## Repository layout

```
index.html                     Standalone preview (runs the dashboard from the CSVs in any browser)
dashboard/index.html           Dashboard page source, as published in Claude's dashboard runtime
data/apac_staffing_forecast.csv  One row per person per week (137 people × 8 weeks)
data/apac_pipeline.csv           26 open opportunities with stage, probability, start, FTE and skills needed
scripts/generate_sample_data.py  Reproducible generator for both CSVs (fixed seed)
```

`dashboard/index.html` relies on a host runtime that provides the `dash` API (`dash.data`, `dash.draw`, `dash.params`, …), d3 v7 and design tokens. The root `index.html` supplies a minimal stand-in for that runtime, so the same page runs unchanged from static files.

## Run it

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

It must be served over HTTP (not opened as a `file://` path) because it fetches the page and CSVs. It also works as-is on GitHub Pages.

To regenerate the sample data:

```bash
python3 scripts/generate_sample_data.py
```

## Going to production

Replace the two CSVs with live sources: the resourcing tool (e.g. Kantata, Runn, Float) for capacity, bookings and leave; timesheets for actuals; the CRM for pipeline stage and probability; and an HR or skills system for titles and certifications.
